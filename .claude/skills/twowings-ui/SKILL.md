# Интерфейс 2Wings

Сначала прочитай раздел «Интерфейс: Fluent Design» в `AGENTS.md`. Образец экрана — параметры Windows 11; при сомнении следуй [рекомендациям Fluent](https://learn.microsoft.com/windows/apps/design/).

## Порядок

1. Сначала стандартный элемент QFluentWidgets, затем хелпер из `src/ui/components`. Своего контрола, цвета и шрифта не заводить. Иконки — только `Lucide("имя")`, не `FluentIcon`. Наследовать меню QFluentWidgets нельзя: наследник теряет их `exec()`.
2. Настройка — `switch_card` или `select_card` в `Group`. Текст настройки — заголовок и описание, а не отдельная подсказка под ней.
3. Обращение к сети и daemon — через `dispatch.run_bg`; из чужого потока к виджетам — только `dispatch.ui_call`.
4. Таймеры и подписки страницы снимаются в её `stop()`.
5. Тексты — на русском, языком пользователя. Короткие сообщения без точки в конце. Долгая операция сразу показывает `show_toast`.
6. Название программы в текстах — только через `APP_NAME`.

## Проверка

`python run.py` запрашивает UAC и без daemon не стартует. Страницы без daemon проверяются обходом окна с подменённым `is_daemon_running` и `APPDATA`, указывающим на временную папку. Проверь и минимальный размер окна, 860×600: полоса кнопок не должна вылезать за край страницы.
