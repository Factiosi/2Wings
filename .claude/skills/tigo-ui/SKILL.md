# UI Tigo

Язык — `docs/UMBRAE.md` и `docs/STYLE.md` в Factiosi. Поведение Flet, на котором уже обжигались, — [flet.md](flet.md) (копия из Factiosi; при расхождении верен Factiosi). В `AGENTS.md` — разделы «Дизайн» и «UI: кастомный select», подробно про select — `docs/AGENTS-UI-SELECT.md`.

## Порядок

1. Цвет, кегль, радиус, длительность — только `T.*` из `src/ui/theme/__init__.py`. Источник — `src/ui/theme/umbrae.py`, копия Factiosi: обновляет `scripts/sync_umbrae.ps1`, руками не правят. Hex не выдумывать. Flet читает `#AARRGGBB`.
2. Контролы — из `src/ui/components/` (`make_select`, кнопки, `lucide_icon`). `ft.Dropdown` и Material-иконки не ставят. Новая иконка — SVG из `lucide-static` в `assets/icons/lucide/`.
3. Радиусы: кнопка, поле, карточка, пункт рельса — 6; панель, меню — 8; бейдж — 4; галочка — 2. Акцент один — фиолетовый.
4. Одно действие — один `page.update()`; анимация — два кадра через `page.run_task`. Фоновая работа не трогает страницу из своего потока. GUI говорит с daemon только через IPC и не замораживает окно сокетом.
5. Тексты интерфейса — на русском, языком пользователя. Долгая операция сразу показывает тост («Спрашиваю адреса у DNS…»).
6. Пункты DNS и hosts и выбор источника стратегий видны только при `settings.advanced_mode`.

## Проверка

Окно: `python run.py` (поднимет UAC, без daemon не стартует). Горячей перезагрузки нет — после правки страницы окно перезапускают. Окно отладки — `src/ui/features/debug_console/`.
