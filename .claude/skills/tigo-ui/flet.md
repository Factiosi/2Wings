# Flet: что ломалось и как это держится в Tigo

Числа — в `python/umbrae.py` (сборка `tokens/umbrae.json`), правила — в `docs/UMBRAE.md`. Здесь только поведение Flet, из-за которого экран врал или тормозил.

Длительности только из шкалы Umbrae (`duration-*`): fast 100, base 200, moderate 300, slow 500 мс. Наведение кнопки и галочка — fast, раскрытие — moderate. Блики знака и рельса — по периодам `umbrae-sheen-period` и `umbrae-rail-sheen-period`.

## Цвет

Flet читает `#AARRGGBB`. Запись `#RRGGBBAA` становится другим цветом: `#bcc6f31a` — это альфа `BC` у `#c6f31a`, на тёмной странице глаз видит оливковый около `#99ba1a`. Так зеленели наведение галочки, заливка контурной кнопки, дорожка кольца и «мытые» плашки статусов.

Прозрачность считают так:

```python
def argb(hex_color: str, alpha: int) -> str:
    return f"#{alpha:02x}{hex_color.removeprefix('#')}"
```

`#00000000` прозрачен в обоих порядках. Им гасят Material-вспышку. Смесь «10% цвета кнопки» — `argb(button, 0x1A)`, «5%» — `0x0D`, дорожка кольца 30% — `0x4D`.

Наведение заливной кнопки в тёмной теме — чёрная вуаль `#29000000`, в светлой — белая `#29ffffff`. Это 16% и кладётся в `overlay_color` состояния `HOVERED`. Контур при наведении берёт `argb(button, 0x1A)`, не зелёный и не акцент схемы. Удаление красится цветом ошибки.

Плашка статуса — сплошной success, warning, error или line-strong. Текст чёрный или белый:

```python
def ink(hex_color: str) -> str:
    raw = hex_color.removeprefix("#")
    red, green, blue = int(raw[0:2], 16), int(raw[2:4], 16), int(raw[4:6], 16)
    luminance = 0.2126 * red + 0.7152 * green + 0.0722 * blue
    return "#000000" if luminance > 150 else "#ffffff"
```

Полупрозрачный хвост у hex статуса не используют.

## Один update на действие

`page.update()` рисует страницу целиком. Два вызова подряд из одного обработчика клика Flet сливает в последний. Поэтому список, у которого в одном заходе ставят `opacity = 0` и тут же `opacity = 1`, появляется уже открытым.

Правило из Tigo:

- обработчик клика сам не вызывает `page.update()`, если его обернули: обёртка закрывает список и делает один `page.update()` в конце;
- у уже показанного куска зовут `control.update()`, не всю страницу;
- смена двух кадров анимации — это два прохода. Первый кадр уходит в `page.update()` или `control.update()`. Второй кадр ставит `page.run_task`: `await asyncio.sleep(0.05)`, затем конечные `opacity` и `scale`, затем `control.update()`.

Тост в `notifications.py` устроен так же: кадр «скрыт» обновляется, пауза 0.05 с, кадр «виден».

Фоновая работа не трогает страницу из своего потока. Поток считает результат, на страницу возвращаются через `page.run_thread`. Опрос демона в тесте идёт через `asyncio.to_thread`, иначе сокет на 2 с замирает окно.

## Выпадающий список

Это не `ft.Dropdown`. Поле — контейнер фиксированной высоты, меню — контейнер в `page.overlay`.

- Ширина меню равна ширине закрытого поля. Ширину запоминают в `on_size_change`. Пока замера нет, подстановка 280 врёт: меню шире поля.
- Пункт 38 px, радиус пункта 8, радиус меню 12, шаг пунктов 4, поля меню 4. Выбранный пункт — фон `selected`, текст цвета кнопки. Наведение — `highlight`.
- Меню кладут последним в `overlay`, иначе его перекрывает другой слой. Перед повторным добавлением его снимают.
- Позиция берётся из `TapEvent`: `global_position` минус `local_position` — левый верх поля. `Container.on_click` отдаёт `Event` без этих полей, список падает. Жест вешают на `GestureDetector.on_tap`.
- Открытие: `visible = True`, `opacity = 0`, `scale = 0.95`, стрелка ещё не в конце, один `page.update()`. Затем задача через 0.05 с ставит `opacity = 1`, `scale = 1` и обновляет только меню. Выравнивание масштаба — верх, если меню открылось вниз, и низ, если вверх.
- Через 0.32 с у меню обнуляют `animate_opacity` и `animate_scale`. Иначе прокрутка страницы снова гоняет вход. При закрытии анимации возвращают, opacity снова 0, scale 0.95, контрол убирают из overlay.
- Стрелка создаётся с `Rotate(0)` и `animate_rotation` на 200 мс. Поворот на π ставят при открытии уже существующей иконки. Иконка, собранная сразу повёрнутой, не анимируется.
- Клик снаружи и Escape закрывают меню. Второй список закрывает первый до своего открытия.

## Раскрытие, которое не список

Плашка стратегии — галочка слева и раскрытие справа, между ними линия в 1 px. Левый жест переключает галочку, правый меняет высоту тела. Это не меню.

Тело и стрелка живут в словаре по id. Жест меняет высоту, opacity и padding уже стоящего контейнера и поворот уже стоящей стрелки. Замена всей строки на заново собранную открытую строку показывает конечный кадр сразу: высота уже полная, стрелка уже повёрнута.

Пока идёт прогон тестов, ручное раскрытие не принимают. После прогона политика раскрытия сама решает, какие id открыты. Её не переписывают вместе с вёрсткой.

## Лаг от лишней перерисовки

Каждый тик пробы не пересобирает список стратегий.

- События пробы копят 120 мс и сбрасывают пачкой только грязные id.
- Таблица пробы при том же порядке строк не создаёт строки заново. Она меняет текст ячейки. Кольцо загрузки хранят по ключу ячейки и подставляют тот же объект, пока фаза `loading`. Новый объект на каждый тик перезапускает вращение и дёргает строку.
- Смену статуса применяют к затронутым строкам. Полную пересборку списка оставляют на смену состава, не на каждый пакет сокета.
- `page.update()` на каждый тик опроса не зовут, если изменились только ячейки: обновляют тело таблицы.

## Кольцо

`ProgressRing` тянется на ширину ячейки и становится овалом. У него свой минимум около 36 px, свой padding и `track_gap`. Кольцо кладут в контейнер с равными шириной и высотой и задают

```python
size_constraints=ft.BoxConstraints(
    min_width=size, max_width=size, min_height=size, max_height=size,
)
```

плюс `padding=0`, `track_gap=0`, `year_2023=True`, толщина 2. Цвет — цвет кнопки. Дорожка — `argb(button, 0x4D)`. Ячейку не растягивают на всю ширину колонки: кольцо остаётся квадратом слева.

## Галочка

Круг при наведении — Material, у Umbrae его нет: меняется только цвет.

`hover_color` и `splash_radius` ставят на сам `ft.Checkbox`. В `CheckboxTheme` аргумент `hover_color` даёт `TypeError`. В теме гасят overlay состояний `HOVERED`, `FOCUSED`, `PRESSED` цветом `#00000000`. У страницы `splash_color="#00000000"`. Заливка выбранной галочки — цвет кнопки, черточка — `on-primary`.

Flet не отдаёт отдельную скорость росчерка. Ускорить один только штрих средствами темы нельзя.

## Кнопки, поле, вкладки, шрифт

Геометрия Umbrae, одна роль — один радиус: кнопка, поле, карточка, пункт рельса — `radius-button`/`-input`/`-card` (6), панель 8, бейдж 4, чекбокс 2. Высота кнопки и поля — `size-control-md` (36). Кнопки: главная — заливка акцентом, вторичная — обводка сильной линией, удаление — обводка и текст цветом ошибки.

Поле: заливка впадины, рамка 1 px сильной линии, в фокусе — цвет фокуса. Рамки задают через `border={ControlState.DEFAULT: OutlineInputBorder(...), ControlState.FOCUSED: ...}`: `border_color` и `border_radius` у `TextField` устарели в Flet 1.0. Подпись над полем, не плавающая подпись Material.

Вкладки: Inter 500, подчёркивание 2 px цветом акцента под выбранной, остальные — третичный текст.

Cormorant и Inter регистрируют в `page.fonts` до первого `update`. Ключ — имя семейства, значение — путь к файлу в `assets/fonts`. Тело остаётся Segoe UI. Цвет ставят на конкретный `Text`, не общей темой «все подписи одного цвета», если роли разные.
