# Закон имён

Схема одна, второй не заводят.

## Корень

В корне лежат только вход, конфигурация запуска и каталоги из списка. Свободных файлов нет: ни SVG, ни архивов, ни черновиков.

| Имя | Есть всегда | Что это |
|-----|-------------|---------|
| `README.md` | да | Как запустить этот репозиторий. Не справочник по дизайну |
| `AGENTS.md` | да | Как агенту продолжать работу именно здесь |
| `CLAUDE.md` | да | Указывает на `AGENTS.md` |
| `docs/` | да | Объяснения, которые нельзя смешивать с README |
| `assets/` | да | Файлы, которые не являются кодом программы |
| `tools/` | когда есть генераторы | Сборка логотипов, иконок, инсталлятора. Не код, который запускает пользователь |
| `scripts/` | когда есть команды | Команды с машины разработчика |
| `ops/` | только у продукта с отдельным рантаймом | nginx, compose, sidecar. Не бизнес-логика |

Запрещены: `archive/`, `explorations/`, второй комплект тех же логотипов.

В git не входят `node_modules/`, `dist/`, `.venv/`, `.run/`, `.env`, базы и кэши тестов.

## Где живёт код

Один корень кода: `src/`.

Внутри программы с интерфейсом:

```text
src/ или apps/<ui>/src/
  components/     контролы без знания экрана
  pages/          экраны, если их мало и они плоские
  features/       экран вместе со своей логикой, если экран толстый
  theme/          только переключатели темы, не вторая палитра
```

`pages/` и `features/` не дублируют один экран.

Слои:

```text
src/core/       настройки, пути, процесс
src/ui/         окна и страницы
src/modules/    способности продукта
src/daemon/     то, что живёт без окна
src/kernel/     граница с ОС
```

Новый слой заводят, только когда код не входит ни в один из этих. Папки «разное» нет.

Тесты лежат в корневом `tests/`. Третьего места для них нет.

## Знаки

Мастера лежат в `assets/brand/`. Инструменты сборки — в `tools/`, их выход снова под `assets/`. Значки интерфейса и трея — `assets/icons/`.
