# Закон имён

Этот текст повторяет правила Factiosi для агента, который работает в другом репозитории дома. Продукт не придумывает вторую схему.

## Корень

В корне лежат только вход, конфигурация запуска и каталоги из списка. Свободных файлов нет: ни SVG, ни архивов, ни черновиков.

| Имя | Есть всегда | Что это |
|-----|-------------|---------|
| `README.md` | да | Как запустить этот репозиторий. Не справочник по дизайну |
| `AGENTS.md` | да | Как агенту продолжать работу именно здесь |
| `CLAUDE.md` | да | Указывает на `AGENTS.md` |
| `docs/` | да | Объяснения, которые нельзя смешивать с README |
| `assets/` | да | Файлы, которые не являются кодом программы |
| `tools/` | когда есть генераторы | Сборка логотипов, иконок, инсталлятора. Не код, который запускает пользователь |
| `scripts/` | когда есть команды | Команды с машины разработчика |
| `ops/` | только у продукта с отдельным рантаймом | nginx, compose, sidecar. Не бизнес-логика |

Запрещены: `archive/`, `explorations/`, `design-systems/`, каталог чужих брендов, второй комплект тех же логотипов (`*-handoff`, `brand-export`).

В git не входят `node_modules/`, `dist/`, `.venv/`, `.run/`, `.env`, базы и кэши тестов.

## Где живёт код

Один корень кода. Смешивать варианты нельзя.

| Какой репозиторий | Корень кода |
|-------------------|-------------|
| Несколько отдельных программ | `apps/<программа>/` |
| Одна программа | `src/` |
| Канон дизайна Factiosi | `tokens/`, `web/`, `python/` |

`web/` и `python/` в корне разрешены только в Factiosi. В продукте веб-клиент — `apps/web/`.

Внутри программы с интерфейсом:

```text
src/ или apps/<ui>/src/
  components/     контролы без знания экрана
  pages/          экраны, если их мало и они плоские
  features/       экран вместе со своей логикой, если экран толстый
  theme/          только переключатели темы, не вторая палитра
```

`pages/` и `features/` не дублируют один экран.

Слои десктопного приложения с фоном и системой, образец 2Wings:

```text
src/core/       настройки, пути, процесс
src/ui/         окна и страницы
src/modules/    способности продукта
src/daemon/     то, что живёт без окна
src/kernel/     граница с ОС
```

Новый слой заводят, только когда код не входит ни в один из этих. Папки «разное» нет.

Код сервера — в `apps/api/app/`. Тесты этого сервера — в `apps/api/tests/`. У одной программы тесты лежат в корневом `tests/`. Третьего места для тестов нет.

## Бренд

```text
assets/brand/
  sources/      исходники знака
  *.svg         готовые мастера
```

Инструменты сборки — в `tools/`. Их выход снова под `assets/`. Иконки интерфейса, которые не являются маркой, — `assets/icons/`. Копия знака рядом с клиентом — ссылка на мастер, не второй рисунок.

## Документы

| Файл | Кто пишет | О чём |
|------|-----------|--------|
| `README.md` | каждый репозиторий | запуск и что это за продукт |
| `docs/STRUCTURE.md` | только Factiosi | этот закон |
| `docs/STYLE.md` | только Factiosi | как рисовать интерфейс |
| `docs/UMBRAE.md` | только Factiosi | язык Umbrae, включая знаки |
| `docs/LOG.md` | только Factiosi | релиз, тестовая версия, коммиты, две ветки |
| `docs/ARCHITECTURE.md` | продукт, если есть сложный конвейер | как устроен продукт, не папки |

Удаляют, а не архивируют: черновик, который уже заменён; второй экспорт того же SVG; библиотеку чужих дизайн-систем; инструкции, которые описывают удалённые каталоги. Историю хранит git.

Старый канон Factiosi удалён. Папку `prior/` не восстанавливают и в других репозиториях не заводят.
